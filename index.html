iPad에서 인터넷 없이 사용하기

처음 한 번은 인터넷에 연결하여 준비하세요. 준비가 끝나면 홈 화면 아이콘으로 앱을 열어 오프라인에서 사용할 수 있습니다.

  1. 인터넷 연결 상태에서 iPad의 Safari로 Text Highlighter를 여세요.
  2. 로딩 완료까지 기다리기
    앱 화면과 PDF 처리 기능이 모두 불러와질 때까지 기다리세요. 오프라인 사용에 필요한 파일이 기기에 저장됩니다.
  3. 홈 화면에 앱 추가
    Safari의 공유 (Share) 버튼을 누른 뒤 홈 화면에 추가 (Add to Home Screen)를 선택하세요.
  4. 홈 화면 아이콘으로 한 번 열기
    인터넷을 연결한 채 Text Highlighter 아이콘을 눌러 앱이 정상적으로 열리는지 확인하세요.
  5. 오프라인 작동 확인
    비행기 모드 (Airplane Mode)를 켜고 Wi-Fi도 끈 뒤, 홈 화면 아이콘으로 앱을 다시 열어 PDF를 처리해 보세요.

업데이트 후에는 인터넷에 연결한 상태로 앱을 한 번 열어 최신 파일을 저장한 뒤 오프라인으로 사용하세요.
