Offline Ready Smart Text Highlighter & Route Matcher

앱 기능 한눈에 보기 키워드 · Duty Time · Route · 북마크 · EDTO 펼쳐보기 접기
01키워드 하이라이트
PDF 텍스트를 보정하고, 기본·사용자 키워드와 위험 문장을 색상이나 밑줄로 강조합니다.
02Duty Time
CFP의 TRIP 시간에 따라 1/2 또는 2/3·1/3 지점을 계산해 PDF에 표시합니다.
03Route 복사·대조
CFP 경로를 ATS FPL 페이지에 복사하고, 경로·기체·출도착·운항일 정보의 차이를 표시합니다.
04FIR Entry Time
ETD에 ATS FPL의 EET를 더해 FIR 진입 예정 시각을 UTC로 표시합니다.
05EDTO·대체공항 시간 복사
CFP의 Suitable From/To UTC 시간대를 NOTAM의 ERA·EDTO·REFILE 공항 옆에 복사해 표시합니다.
06WPT·Track 매칭
CFP에서 검출한 WPT가 NOTAM에 있으면 밑줄로 표시하고, 운항 Track도 찾아 강조합니다.
07출도착·TAF 시간
출도착 ETD·ETA와 날짜 변경을 표시하고, TAF에 공항명·역할과 확인 가능한 시간을 붙입니다.
08기상 구간 시간
FROM WPT TO WPT 구간에 CFP의 WPT 시간을 연결해 시작·종료 시간을 표시합니다.
09연료 정보 배지
DISPATCH NOTES에 DISC 연료·시간을 복사하고, REFILE POINT 연료와 RQRD의 차이를 표시합니다.
10섹션·공항별 북마크
CFP·ATS·Dispatch·ETP·기상·NOTAM과 공항·FIR별 북마크를 만듭니다. 기존 북마크 유지도 지원합니다.
11기상·운항 정보 강조
기상 위험, Shear·MSA·ETP 정보를 강조하고, 비적용 안내·EXC SKED·NOTAM 3 회색 영역 규칙을 반영합니다.
12오프라인 처리·PDF 저장
기기에서 PDF를 처리하고 날짜·편명·경로를 반영해 저장·공유합니다. 준비 후에는 인터넷 없이 사용할 수 있습니다.

문서에 해당 정보가 있을 때 자동 기능이 적용됩니다.

iPad에서 인터넷 없이 사용하기

처음 한 번은 인터넷에 연결하여 준비하세요. 준비가 끝나면 홈 화면 아이콘으로 앱을 열어 오프라인에서 사용할 수 있습니다.

  1. 인터넷 연결 상태에서 iPad의 Safari로 Text Highlighter를 여세요.
  2. 로딩 완료까지 기다리기
    앱 화면과 PDF 처리 기능이 모두 불러와질 때까지 기다리세요. 오프라인 사용에 필요한 파일이 기기에 저장됩니다.
  3. 홈 화면에 앱 추가
    Safari의 공유 (Share) 버튼을 누른 뒤 홈 화면에 추가 (Add to Home Screen)를 선택하세요.
  4. 홈 화면 아이콘으로 한 번 열기
    인터넷을 연결한 채 Text Highlighter 아이콘을 눌러 앱이 정상적으로 열리는지 확인하세요.
  5. 오프라인 작동 확인
    비행기 모드 (Airplane Mode)를 켜고 Wi-Fi도 끈 뒤, 홈 화면 아이콘으로 앱을 다시 열어 PDF를 처리해 보세요.

업데이트 후에는 인터넷에 연결한 상태로 앱을 한 번 열어 최신 파일을 저장한 뒤 오프라인으로 사용하세요.
