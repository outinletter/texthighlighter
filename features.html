01WEATHER BRIEFING

날씨를 읽는 자리에서, 출발·도착 시각까지.

TAF 공항 정보 옆에 출발 공항의 ETD, 도착 공항의 ETA와 공항 역할 배지를 표시합니다. 시간 정보를 다시 찾으러 비행계획 페이지로 돌아가지 않고, 해당 공항의 기상과 예정 시각을 같은 페이지에서 참고할 수 있습니다.

표시 예시 · 실제 비행 데이터 아님
DEP RKSI 0900Z
DEST KLAX 2000Z

출발·도착 시각을 기상 정보와 함께 참고

공항 코드와 비행계획 시각이 인식된 경우 표시합니다. 다른 공항은 매칭되는 웨이포인트 시각을 사용하며, 찾지 못한 시각은 TIME N/A로 표시합니다.

02EDTO · ENROUTE ALTERNATES

대체공항 NOTAM 옆에 필요한 시간 구간을.

CFP의 ENROUTE ALTERNATES에 기재된 SUITABLE FROM / TO 정보를 찾아 EDTO·ERA·REFILE 공항의 NOTAM 헤더 옆에 표시합니다. 공항별 시간 구간을 확인하기 위해 CFP와 NOTAM 사이를 반복해서 이동할 필요가 줄어듭니다.

표시 예시 · 실제 비행 데이터 아님
[EDTO] RJAA
From 1200Z To 1430Z

공항 코드와 시간 구간을 한눈에 대조

이 배지는 CFP에 기재된 적합 시간 구간을 옮겨 표시합니다. 가장 빠른·가장 늦은 도착 예정 시간을 새로 계산하는 기능은 아닙니다.

03NOTAM 3 · FIR ENTRY

이 FIR에 언제 진입하는지, NOTAM에서 바로.

비행계획의 출발 예정 시각과 EET/ 경과시간을 연결해 FIR 진입 예정 시각을 계산합니다. NOTAM 3의 해당 FIR 헤더 옆에 FIR ENTRY와 UTC 시각을 표시해, 시간과 관련 NOTAM을 같은 자리에서 참고할 수 있습니다.

표시 예시 · 실제 비행 데이터 아님
[FIR] RJJJ
FIR ENTRY · 11:20Z

시각을 찾기 위한 페이지 이동 줄이기

출발 예정 시각, EET/ 값과 해당 FIR 코드가 매칭될 때 생성됩니다.
